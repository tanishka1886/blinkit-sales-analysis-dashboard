# Blinkit Sales Analysis Dashboard

## About the Project

This project is an interactive Power BI dashboard created to analyze Blinkit sales data.

The dashboard helps to understand sales performance and compare different outlet types, locations, and product categories.

## Tools Used

- Power BI
- Microsoft Excel

## Key Analysis

- Total Sales
- Average Sales
- Number of Items
- Average Rating
- Sales by Outlet Type
- Sales by Outlet Location
- Sales by Item Type
- Sales by Fat Content
- Outlet Establishment Trends

## Dashboard Features

- Interactive charts and visuals
- KPI cards for important metrics
- Filters and slicers for exploring the data
- Comparison of sales across different outlet categories

## Key Insights

The dashboard provides an overview of sales performance and helps identify patterns across different outlet types, item categories, and locations.

## Project Purpose

The main purpose of this project was to practice data analysis and visualization using Power BI and turn raw sales data into an interactive dashboard.
